## HEAR editorial sample

`hear-editorial-base-v1.png` was edited with the built-in image-generation tool from three local inputs: the earlier HEAR concept cover (semantic-composition reference), `content/publications/hear/historizer.jpg` (technical reference), and `content/publications/hear/robot-platforms.jpg` (hardware reference). Final prompt:

> Use case: scientific-educational. Asset type: 16:9 research-paper cover illustration for an academic website. Input images: Image 1 is the edit target and semantic-composition reference; Image 2 is the authoritative technical reference for causal audio memory across a blind execution interval; Image 3 is the authoritative reference for the real robot hardware. Preserve the research story from Image 1, not its glossy CGI finish. Primary request: Reinterpret the HEAR cover as one integrated scientific editorial illustration that explains the method at a glance. Show a real robot performing a tabletop sound-dependent manipulation task. A brief acoustic event occurs during an action chunk, ends, but remains visibly retained as a causal memory trace until the robot's next decision. Continue the same visual path through four distinct conceptual moments: retained audio evidence, scene/task-stage reasoning, near-future audio prediction, and the next continuous robot action. The viewer should understand that a transient sound changes what the robot does next. Scene/backdrop: believable robotics laboratory or modest kitchen workbench, with the robot hardware grounded in a real physical scene; a restrained timeline and waveform may be drawn over or around the scene as scientific annotation, never as magical energy. Style/medium: mature scientific editorial illustration, hand-rendered gouache and graphite with subtle paper grain; observational detail, small imperfections, real materials; composed like a carefully made journal explainer rather than a presentation slide. Composition/framing: wide continuous 16:9 scene, left-to-right causal flow; one dominant robot task, not four repeated display cards. Leave several small calm regions near the flow where exact labels can be added later. Lighting/mood: natural soft daylight, calm analytical mood. Color palette: muted charcoal, warm off-white, clay orange, dusty blue, restrained teal accents. Technical constraints: causal audio memory must bridge the blind execution interval after the original waveform has ended; do not imply that sound is continuously present; do not anthropomorphize the model; the four conceptual stages must be visually distinct but integrated into one scene. Text constraints: no words, no letters, no numbers, no pseudo-text, no labels; exact typography will be overlaid later. Avoid: glossy 3D rendering, sci-fi interfaces, neon glow, holograms, translucent glass cards, floating UI panels, advertising polish, symmetrical product-shot layout, generic robot mascot, giant brain icon, decorative data streams, excessive bloom, watermark.
