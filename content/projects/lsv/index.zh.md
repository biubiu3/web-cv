自动驾驶的硬核突破，永远始于让算法在真实的物理世界中奔驰。从传感器光子捕捉、毫米级时空对齐、因子图定位优化，到底盘执行机构毫秒级响应与动态车辆动力学闭环，任何脱离实车硬件的仿真都无法揭示真实世界的极端边界。**2019–2022 年间，我独立主导从零搭建了这套低速自动驾驶全栈科研平台，完成了从线控硬件架构改装、电气布线、CAN 总线驱动到底层至上层全栈 ROS 算法体系的完整闭环开发。**

## 两种底盘形态，共同的科研流程

项目资料展示了两类平台：一类是带座位与设备支架的开放式低速车，另一类是搭载传感器和计算设备的紧凑四轮 AGV。前者便于布置设备和随车观察，后者在较小车体上组织同样的科研流程。底盘方案中还包含四轮独立驱动与转向配置。

两类平台都将车辆硬件接入感知、定位、规划与控制软件，使算法能够在真实运动中运行。传感器更新频率不同、安装位置影响视野、控制指令与底盘响应存在差异，这些问题都可以通过实车实验观察和分析。

## 硬件组成：看见道路，也能执行运动

| 设备 | 在科研小车中的作用 | 集成时需要处理的问题 |
|---|---|---|
| 摄像头 | 为目标识别与车道观察提供图像 | 视场范围及其与车体坐标的关系 |
| 激光雷达 | 为障碍物感知、建图和地图定位提供距离观测 | 安装位置、车体遮挡与点云对齐 |
| RTK GNSS | 为室外循迹实验提供位置参考 | 天线布置、接收条件与坐标转换 |
| IMU | 测量角运动与加速度 | 安装方向、偏置与时间戳一致性 |
| 超声波雷达 | 观测车身周围的近距离障碍物 | 保险杠附近的覆盖范围与盲区 |
| 工控机与 HMI | 运行车载软件并显示系统状态 | 供电、通信、固定方式与调试可达性 |
| 线控底盘与 CAN | 执行运动指令并传递车辆状态 | 指令单位、转向约定与反馈解析 |

实车资料中可以看到传感器立柱、GNSS 天线、显示器和车载计算设备围绕底盘布置。各类传感器提供互补信息：摄像头描述外观，激光雷达测量空间结构，GNSS 提供室外位置参考，IMU 记录运动变化，超声波传感器补充车身近处的距离观测。

## 软件架构：从传感器观测到车辆运动

项目软件采用 **Ubuntu 与 ROS**，包含感知、GPS／地图定位、决策规划、控制和 CAN 总线模块。下图依据项目架构重新组织主要数据流。

### 环境感知与车辆定位

感知分支面向多目标识别、车道观察和激光雷达障碍物感知。定位分支连接 GPS／RTK 定位与激光雷达建图，提供车辆相对路线或地图的位置。这些信息共同回答车辆在哪里、周围有什么，以及可以向哪里行驶。

项目资料分别记录了 RTK 循迹与 SLAM 循迹。前者依赖卫星定位参考，后者依赖激光地图中的位置估计。把两类配置接入车辆控制时，都需要处理传感器、地图与车体坐标之间的关系，使参考路线能够转化为车辆可执行的运动目标。

### 决策规划、车辆控制与底盘接口

决策规划模块根据环境与车辆状态组织驾驶目标，控制模块再通过 CAN 通信向底盘发送运动指令。车辆状态反馈将软件发出的指令与实际运动连接起来，形成持续更新的控制过程。

集成工作的重点在于接口一致性。转向正负方向、速度单位、坐标约定和观测时间都会影响下一步控制。明确这些接口，也方便后续替换定位或感知算法，沿用已有的车辆硬件和其他软件模块。

## 平台技术主导与科研基石价值

作为该自主科研平台的**总负责人与全栈架构师**，我独立攻克并打通了从底层硬件电气化到底层至上层全栈算法的完整链路：
- **软硬件一体化自主架构**：主导设计完成面向多传感器（LiDAR/Camera/GNSS/IMU）的高精硬件拓扑布局、微秒级时钟硬同步与车载稳压供电总线，逆向破解底盘线控 CAN 协议并编写高确定性驱动；
- **全栈 ROS 核心算法闭环**：自研实现多传感器融合定位、3D 激光点云特征提取与回环检测、视觉车道线多项式拟合、多障碍物卡尔曼跟踪以及结合纯跟踪与模型预测控制（MPC）的底盘动力学跟踪；
- **支撑顶级学术与产业成果孵化**：该实车科研平台不仅稳定支撑了本实验室的多项国家级重大科研项目联调，更为我后续在多相机 SfM、视觉-激光融合 SLAM 以及具身机器人多模态大模型领域的突破提供了真实、丰沃的物理试验场！
